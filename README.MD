# Maze Backtracking Solver

A Python implementation of a robot exploring a maze using depth-first search and backtracking.

## Features

- Represents a maze using a 2D grid.
- Finds the starting position and exit.
- Explores neighbouring cells while tracking visited positions.
- Backtracks when it reaches a dead end.
- Displays the successful route and explored cells.
- Counts visited cells and backtracking moves.

## How to Run

Requires Python 3.

```bash
python main.py
```

## Concepts Demonstrated

- Two-dimensional grids
- Loops and conditional logic
- Tuples and sets
- Stack-based depth-first search
- Backtracking and pathfinding
